# Chat with PDFs (Local AI)

A simple Python app that lets you upload PDFs and chat with them using a local AI model. It uses **Chainlit** for the interface and **LangChain** for the AI logic.

## ⚡ Quick Start

### 1. Install Requirements
Make sure you have Python installed, then run:

```bash
pip install chainlit langchain langchain-huggingface langchain-community langchain-text-splitters pypdf faiss-cpu transformers torch accelerate
